# Combat interaction rules
- Tapping a skill selects it immediately; there is no redundant "Use skill?" confirmation.
- Targeted skills execute after tapping a valid target.
- Precise Strike flow is: tap Precise Strike -> tap target -> choose body part -> attack.
- End-turn confirmation is the only configurable confirmation and can be disabled in Settings.
- Skill/toolbar visuals use SVG icons, not Unicode/emoji symbols.
- Music is a packaged local asset and starts from a user gesture.
