Версии Eirdan

Краткая история последних игровых изменений.
0.40.1-alpha · diagnostic-50 · Atomic UpdaterПроверка версии больше не блокирует запуск. build.json используется только как уведомление о новой сборке; загрузка выполняется отдельным действием, а при ошибке сети запускается текущая версия.
0.40.1-alpha · diagnostic-50 · Updater HotfixИсправлен бесконечный цикл загрузчика при переходе между диагностическими сборками: свежая страница теперь передаётся напрямую без повторного browser reload.
0.40.1-alpha · diagnostic-50 · Inventory 2.0Начата физическая система инвентаря: единое окно персонажа и сумки, предметы W×H, двумерная сетка рюкзака, вес содержимого и контейнеры с собственным содержимым.
0.40.0-alpha · diagnostic-50 · Systems AlphaНовая схема версий. Зафиксированы ROADMAP и DEVLOG; текущий основной этап разработки — Inventory 2.0.
diagnostic-50 · Надёжное обновлениеЗагрузчик больше не подменяет документ на лету: после получения новой сборки выполняется чистый переход на свежий index.html, что устраняет зависание на повторной проверке.
diagnostic-50 · Типографика и fullscreenДобавлены Alegreya для заголовков и PT Sans для интерфейса. Исправлено положение нижней версии в полноэкранном режиме.
diagnostic-50 · Читаемость и полный экранТекст светлой темы получил отдельную контрастную палитру. Полноэкранный режим учитывает безопасные отступы экрана и адаптивно размещает поле боя.
diagnostic-50 · Настройки интерфейсаПроверка обновлений перенесена в окно версий, полноэкранный режим — в настройки. Добавлены тёмная и тёплая светлая темы с сохранением выбора.
diagnostic-50 · Меню приложенияДобавлены ручная проверка/обновление версии, полноэкранный режим и подтверждение выхода из игры.
diagnostic-50 · Combat pacingПрежняя скорость ×0.5 стала новым темпом ×1; остальные скорости соответственно замедлены. При включении автобоя скорость автоматически переключается на ×2.
diagnostic-50 · Tactical HopПередвижение стало пошаговым с небольшим прыжком на каждую клетку; клетки и пешки увеличены без изменения размера/количества клеток поля. Изометрическая проекция подготовлена к высотам.
diagnostic-50 · Combat animation optimizationУбраны лишние пересчёты pathfinding на каждом кадре, объединены animation-frame запросы и скрыт мгновенный телепорт подсветки клетки назначения во время движения.
diagnostic-50 · Tactical MovementИИ теперь использует несколько клеток движения за одно действие в пределах AP, а ручное и ИИ-перемещение получили плавную пошаговую анимацию по изометрическому маршруту.
diagnostic-50 · Hotfix интерфейсаИсправлена синтаксическая ошибка после перехода с hex на square, из-за которой migration-base.js не запускался и все кнопки оставались без обработчиков.
diagnostic-50 · Загрузчик без цикла перезагрузкиОбновление теперь сначала полностью получает и проверяет новый HTML, затем передаёт управление новой сборке внутри текущей страницы вместо бесконечных reload.
diagnostic-50 · Синхронизация обновленийПроверка версии теперь идёт по маркеру на том же GitHub Pages-сервере, что и игра. Во время ожидания публикации прогресс-бар не движется.
diagnostic-50 · Tactical Grid IБой переведён с hex-логики на квадратную сетку: 4 направления, квадратная дистанция/pathfinding и подсветка всей доступной зоны движения. Тап по дальней клетке тратит AP/ST за весь маршрут.
diagnostic-50 · Строгая проверка обновленийЗагрузчик сверяет клиент с отдельным маркером версии на GitHub и не открывает игру, пока GitHub Pages не отдаст нужную сборку.
diagnostic-50 · Android BackУсилен перехват системной кнопки «Назад», включая Combat Lab: браузер больше не должен закрывать игру вместо внутриигрового перехода.
diagnostic-50 · Системная кнопка «Назад»Android Back теперь закрывает оверлеи и ведёт назад по интерфейсу: настройки → меню, локация → регион → мир; после завершённого боя → карта мира.
diagnostic-50 · Настоящая проверка обновленияЭкран запуска теперь не пропускает в меню до проверки свежей сборки; старый service worker и кэши разработки удаляются.
diagnostic-50 · Изометрический бойПервый прототип поля в духе Crawl Tactics: ромбические клетки, изометрическая проекция и подсветка доступного хода.
diagnostic-50 · Управление боемИсправлен pointer-ввод по полю боя; добавлены всплывающие урон, промах и блок щитом.
diagnostic-50 · Ручной бойИсправлено управление на canvas, автобой стал выключаемым, добавлена скорость ×0.5/×1/×2/×4.
diagnostic-50 · Расширенная диагностикаПроверка теперь охватывает районы города, арену, экран версий и загрузчик.
diagnostic-50 · Исправление запускаЗагрузчик больше не зависит от service worker: главное меню откроется даже при ошибке обновления.
diagnostic-50 · Загрузчик обновленийПеред главным меню добавлена проверка свежей версии и принудительное обновление кэша.
diagnostic-50 · ВерсииКликабельная версия в главном меню и журнал изменений.
